# Product Steering

## Purpose
n8n Docker Composeプロジェクトは、AIエージェントを活用したワークフロー自動化プラットフォームを提供する。Playwright MCPとVNC統合により、GUIベースの操作も自動化可能。

## Core Capabilities
- n8nワークフローによる自動化
- Playwrightを活用したブラウザ操作
- AIエージェントとの連携（Gemini、LangChain）
- VNCによるGUI操作の可視化

## Value Proposition
- 定型業務の完全自動化
- GUI操作も含む複雑なワークフロー実行
- LINE通知などの外部サービスとの連携
- Dockerによる環境の再現性確保
